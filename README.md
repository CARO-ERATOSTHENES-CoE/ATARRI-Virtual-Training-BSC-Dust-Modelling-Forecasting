# ATARRI Virtual Training: Dust Modelling and Forecasting (BSC)

Training material developed within the **ATmospheric and solAR Research and Innovation in the Eastern Mediterranean (ATARRI)** project by the **Barcelona Supercomputing Center (BSC)**.

This repository contains the notebooks, datasets, presentations, and supporting material used during the **ATARRI Virtual Training Series**, which introduces atmospheric researchers to Python-based workflows for processing, visualizing, and evaluating atmospheric dust forecasts and observations.

The main goal of the training is to analyze and predict dust events over Cyprus and evaluate the accuracy of atmospheric dust models for the region.

# Overview

The ATARRI Virtual Training Series provides a hands-on introduction to atmospheric data analysis using Python, focusing on the **MONARCH** dust forecasting system and several observational datasets, including:

* Barcelona Dust Regional Center products
* MONARCH dust forecasts
* MPLNET lidar observations
* VIIRS satellite observations
* AERONET aerosol observations

Participants learn how to read, process, visualize, and evaluate atmospheric datasets while developing reproducible scientific workflows using modern Python libraries.

---

# Learning Objectives

By the end of the training, participants will be able to:

* Read and manipulate NetCDF atmospheric datasets.
* Analyze MONARCH dust forecasts.
* Produce publication-quality maps and figures.
* Generate time series and statistical analyses.
* Create animations and interactive visualizations.
* Compare atmospheric models with satellite and ground-based observations.
* Evaluate model performance using Providentia.
* Develop reproducible Python workflows for atmospheric science applications.

# Repository Structure

```text
.
├── conda_envs/
├── csv/
├── functions/
├── logs/
├── plot_outputs/
├── scripts/
├── tools/
├── VT-Session-1/
├── VT-Session-2/
├── VT-Session-3/
└── VT-Session-4/
```

| Folder         | Description                                                                               |
| -------------- | ----------------------------------------------------------------------------------------- |
| `conda_envs`   | Contains `.yaml` files for creating the required Conda environments.                      |
| `csv`          | Temporary directory for storing generated `.csv` files during data processing.            |
| `functions`    | Jupyter notebooks containing helper Python functions used by the main training notebooks. |
| `logs`         | Directory for log files generated by MAPIES.                                              |
| `plot_outputs` | Output directory where figures and plots generated by the notebooks are saved.            |
| `scripts`      | Auxiliary scripts used to execute intermediate processing steps.                          |
| `VT-Session-1` | **Introduction to existing dust products and data structures.**                           |
| `VT-Session-2` | **Data visualization.**                                                                   |
| `VT-Session-3` | **Comparison of forecasts with remote sensing observations.**                             |
| `VT-Session-4` | **Evaluation of forecasts using AERONET and in-situ observations.**                       |
| `tools`        | External tools required for Sessions 3 and 4.                                             |

## Tools

The `tools` directory should contain your own local copies of the following repositories:

* **`mapies`** – Used for plotting and comparing satellite observations with atmospheric models.
* **`providentia`** – Used for on-the-fly evaluation and analysis of atmospheric model data.

# Installation

## Clone the repository

```bash
git clone https://github.com/<your-org>/<repository>.git
cd <repository>
```

## Create the required Conda environment

The table below lists the Conda environments used during the training. Each environment can be installed using its corresponding `environment.yaml` file.

```bash
conda env create -f environment.yaml
```

> **Note**
>
> A Linux operating system is recommended. You will need **Conda**, **Miniconda**, or **Mamba** installed (Miniconda or Mamba are recommended).

| Environment            | Environment file                                 | Training sessions |
| ---------------------- | ------------------------------------------------ | ----------------- |
| **ATARRI v0.0.1**      | `conda_envs/atarri_v0.0.1/environment.yaml`      | Sessions 1 & 2    |
| **MAPIES v0.2.0**      | `conda_envs/mapies_v0.2.0/environment.yaml`      | Session 3         |
| **PROVIDENTIA v3.0.0** | Available from the Providentia GitHub repository | Session 4         |

Each time you open a Jupyter notebook, you will be prompted to select a Python kernel. Please choose the kernel corresponding to the appropriate Conda environment, as indicated by your trainer or in the table above.

To activate an environment from a terminal:

```bash
conda activate <environment_name>
```

If you experience any technical issues during the installation or training, please contact your trainer.

## Launch Jupyter

```bash
jupyter lab
```

or

```bash
jupyter notebook
```
